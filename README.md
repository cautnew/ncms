# NCMS

Um projeto open source de gerenciamento de conteúdo.

## Anotações

- Utilizando Livewire como serviço de front-end.
- Desenvolver a estrutura de dados para composição de páginas.

## Modelos de dados

### Páginas

- Informações obrigatórias
  * Header
  * Meta dados
  * Todos podem ficar em branco, mas deve ser fornecida a opção para preenchimento.
